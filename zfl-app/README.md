# ZFL – Học chữ Hán (React + Tailwind)

- Mở nhanh: double-click `ZFL-Reader.html` (đã đóng gói thành 1 file, chạy offline).
- Chạy dev: `npm install` rồi `npm run dev`.
- Build lại file đơn: `npm run build` → `dist/index.html`.

Dữ liệu mẫu: `src/data.js` (3 câu từ Bài giảng 1, + bảng chữ có pinyin, Hán Việt, bộ thủ, cấu tạo).
Tiến độ thẻ ôn lưu trong localStorage của trình duyệt.
